# Codex — STA4CAD V15 Windows açılış onayı
- Durum: tamamlandı — rezervasyon yok.
- Görev: Kullanıcıya UAC ve SmartScreen durumlarına göre açılış adımlarını açıklama.
- Kontrol: Protokol, son iki günün kayıtları, şerit katalogları, kurulu bundle hedefi ve NETLOAD klasörü incelendi. Microsoft belgeleri kontrol edildi.
- Değişiklik: Yalnız bu kayıt. Windows ayarı, kaynak, derleme ve dağıtım işlemi yok.
- Açık: Uyarının tam metni ve STA4CAD açılış testi kullanıcı tarafında.
- Takip: Kurulu kısayol STA.exe hedefli ve Shell Link RunAsUser bayrağı açık. EXE üzerinde Zone.Identifier yok. Windows ayarı değiştirilmedi, doğrudan açılış kullanıcıya bırakıldı.
